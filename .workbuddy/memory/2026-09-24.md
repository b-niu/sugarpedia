## sugarpedia 全库去 AI 味改写（21 篇正文）

用户反馈文史/科普 Markdown「AI 味太浓，看不下去」，要求润色成自然人写的中文，并点名几处毛病：自设靶子自己打（虚空打靶）、「不是…而是…」句式、「X 是很清楚的」这类断言腔。

**做法**：中度改写——只改叙述姿态，章节划分、表格、数据、引文、图片引用、双链、frontmatter 全部原地保留。

1. 我先手写两个样板定调：`唐代官制：四套坐标…`（标题「官制不是一张表，而是四套坐标」→「四套坐标」；「高适…这一说要打折扣」→「高适到底排第几」）、`矮与射没有互换`（「三处硬伤」→「三处对不上」）。
2. 把整改清单写成规范，派 5 个并行 Agent 分头改其余 19 篇（训诂 7 / 历史 6 / 自然科学 3+航空器 / 计算机 2 篇长文）。
3. 用 Python 脚本做结构守恒校验（对比 git HEAD：图片数、双链数、表格行数、代码块围栏数、h2 数逐一相等，字符数 ≥85%）+ AI 套话正则扫描。

**结果**：AI 套话命中数归零（不是…而是 / 并非…而是 / 不在于…而在于 / 关键在 / 值得注意 / 逐一展开 / 先承认 / 综上所述 / 换句话说 / 目录块）。加粗密度从每千字 8–15 处降到 0–4 处。修回 3 处 Agent 失误（航空器丢失 2 个双链、样板残留「下面逐一展开」、naive 篇残留「值得注意」）。

**沉淀**：规则写进 `sugarvault/discipline/写作纪律.md` 新增「一·六五、去 AI 味的行文纪律」，含禁用句式清单、加粗密度参考、改稿后的机器自查命令。注意 sugarvault 是 git submodule，改动需在该子模块内提交。

**遗留待用户核对**（我未擅自改史实）：唐代官制品级表里几处存疑——白居易太子少傅原文标正二品（唐制东宫三少通常从二品）、贺知章秘书监标正三品（唐制秘书监通常从三品）、高适左散骑常侍标正三品（唐制通常从三品）。
