# SugarPedia

> 个人知识沙盒与多维认知网络。持续生长的网状知识库：从量子物理到计算机底层逻辑，从医学影像原理到历史人物传记，乃至古典训诂学。
>
> 原则：**知识无边界，弱目录结构，强节点链接。**

基于 [Quartz 4](https://quartz.jzhao.xyz/) 构建，发布于 GitHub Pages。

本仓库仅收录客观知识与脱敏后的技术分析，不包含任何个人身份信息、网络配置、硬件资产清单或密钥凭证。详见[设计文档 · 内容安全纪律](./docs/design.md#-内容安全纪律)。
