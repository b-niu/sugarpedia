# Normal 的三重含义：正常、法向量与正态分布

> 三个领域共用一个词，是因为它们共享同一个底层意象——**基准（基准线、基准方向、基准分布）**。

![正态分布：位置基准与尺度基准](../../assets/statistics/normal_dist.svg)

## 一、日常与通用语境：正常（Normal）

- **定义**：表示符合常规预期或群体平均水平的状态，本质上以**统计均值**为基准。
- **量化逻辑**：设群体样本为 {x₁, x₂, …, xₙ}，则"正常范围"通常定义为均值 μ ± kσ（k 为标准差倍数，如医学中常用 k = 1.96 对应 95% 置信区间）。
- **应用实例**：
  - 医学：空腹血糖正常范围 3.9–6.1 mmol/L，基于人群检测数据的统计基准。
  - 社会科学：通过问卷调查确定"正常社交频率"的中位数基准（如每周 3–5 次面对面交流）。

## 二、数学领域：法向量（Normal Vector）

- **定义**：垂直于平面、曲线或曲面的向量，其基准性体现为**几何正交性**。
- **代数表达**：
  - 平面 Π: Ax + By + Cz + D = 0 的法向量 n = (A, B, C)，满足 n·v = 0 对平面内任意向量 v 成立。
  - 曲线 C 在点 P 处的法向量 n(P) 与切向量 τ(P) 正交，即 n(P)·τ(P) = 0。
- **微分几何应用**：曲面 S 的法向量场 N(u, v) 用于定义第二基本形式 II = Ldu² + 2Mdudv + Ndv²，描述曲面弯曲的基准方向。

## 三、统计学领域：正态分布（Normal Distribution）

- **定义**：以均值 μ 为位置基准、标准差 σ 为尺度基准的概率分布，其密度函数为：

$$f(x; \mu, \sigma^2) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)$$

- **基准性证明**：
  - 最大熵性质：在给定均值和方差的连续分布中，正态分布具有最大熵，是"最随机"的基准分布。
  - 中心极限定理（CLT）：当独立同分布随机变量 Xᵢ 满足 E[Xᵢ] = μ、Var(Xᵢ) = σ²，则 (ΣXᵢ − nμ)/(σ√n) 依分布收敛于标准正态 N(0, 1)，表明均值 μ 是渐近分布的天然基准。
- **典型应用**：测量误差建模中，μ 代表真实值，σ 反映仪器精度，误差分布以 μ 为中心形成基准钟形曲线。

## 附记

三个义项的公共词根是拉丁语 *norma*（木匠的矩尺、规则）："符合规矩"→ 正常；"垂直于"（规矩所定的正交关系）→ 法向量；"作为基准的分布"→ 正态分布。这与《"表"字的语义演变时间线》是同一个方法论：一个词的多义网络，往往对应同一个底层意象在不同学科里的投影。
