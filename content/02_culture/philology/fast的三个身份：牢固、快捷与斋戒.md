# fast 的三个身份：牢固、快捷与斋戒

> 一个词同时表示"快"和"不吃东西"，看起来毫无道理。但把词源摊开就会发现：它俩是**同一个词根分出的两支**——古英语 fæst 的本义是"牢固"，一支经由"牢牢地、用力地"变成"迅速地"，另一支经由"坚守戒律"变成"斋戒"。而 breakfast 恰好把这个词根的两个身份缝在了一个词里。

## 一、两件毫不相干的事，共用一个词

- **快速**：a fast car、run fast、fast lane。
- **禁食**：to fast、fasting、break fast。

这两个义项在今天的英语里已经彻底互不相识——一个修饰速度，一个描述吃饭。但它们是同源的，分叉路径可以完整复原，而且分叉的时间点相差上千年。

## 二、牢固：最初的那个意思

古英语形容词 **fæst** 的意思是"牢牢固定、坚定不移、恒常"，再往外延是"安全的、封闭的、防水的、强壮设防的"。它的来源是原始日耳曼语 `*fastu-`（"firm"），再往上可追到原始印欧语词根 `*past-`（"坚实"）。

本文对两类词形做了区分：**加粗的是有文献佐证的实际词形，前面带星号的则是构拟形式**——原始日耳曼语与原始印欧语都没有留下文字，它们的词形是语言学家用比较法反推出来的，因此一律带星号。

这个词根今天仍活着的部分：

| 词 | 残留的"牢固"义 |
|---|---|
| steadfast | 坚定不移（stead + fast，站得牢） |
| fasten | 扣紧、扎牢——它取代了 fast 原本的动词义 |
| hold fast | 抓牢 |
| fast asleep | 熟睡（"牢牢地"睡着，不是"快速地"睡） |
| fastness | 要塞、堡垒 |
| bedfast | 卧床不起 |
| avast | 停住（借自荷兰语 houd vast "hold fast"） |
| 德语 fast | 今天意为"几乎"，早期却是"牢固地、强烈地、非常" |

同源词包括德语 **fest**（坚固）、荷兰语 **vast**、古诺斯语 **fastr**。注意：此时"快"和"斋戒"两个意思都还不存在。

## 三、快捷：副词先跑，形容词后到

这一步的次序值得记牢，因为它常被讲反：

| 形式 | 义项 | 出现时间 |
|---|---|---|
| 副词 fast | 牢牢地、严格地 | 古英语 fæste |
| 副词 fast | 快速地 | 可能在古英语已存在，最迟约 1200 年确证 |
| 形容词 fast | 快速的 | **要等到 1550 年代** |

也就是说，"跑得快"这个说法先在副词里成形，过了三百年才轮到形容词。中间那一步是"**牢牢地、用力地**"——早期英语里 to run hard 和 to run fast 是一个意思，古诺斯语 drekka fast 是"喝得猛"。速度义显然是从"用力、猛烈"这层意思长出来的。

另一种解释走的是"紧贴"的意象：古丹麦语 fast 兼有"多、迅速、立刻、紧贴、几乎"诸义，像是追猎时猎犬紧贴猎物的那种"紧"。这条线索也解释了德语 fast 为什么会变成"几乎"。

这条线的终点是二十世纪的那一串熟词：fast-forward（1948，原指录音磁带快进）、fast buck（1947）、fast food（1951）、fast lane（1966）、fast track（原为赛马术语，1934）。

## 四、斋戒：把"守戒"的劲头用在吃饭上

"禁食"这一支比"快速"早得多：古英语动词 **fæstan** 在古英语时期就已表示宗教性的禁食。它来自原始日耳曼语 `*fastanan`（"持守、守卫"），语义是这么滑过去的：

```text
牢牢持守 → 牢牢约束自己 → 坚守（某种戒律）→ 斋戒
```

**铁证是哥特语的 fastan：它同时表示"遵守、奉行"与"禁食"。** 一个词把中间那座桥直接摆了出来。另一条流行的解释是：日耳曼人用自己的本义为"持守"的词，去翻译中世纪拉丁语 observare（遵守、奉行）在宗教语境下的"守斋"义；也有学者认为这是对某个希腊语表达的仿译，由阿里乌派传教士带进哥特语，再扩散到其他日耳曼语。

有个细节很能说明"牢固"与"斋戒"当初离得多近：晚期古英语名词 **fæsten** 既指"禁食"，而在更早的古英语里，它指的是**堡垒、修道院、围场、监狱**——一堆"圈起来、固定住"的东西。同一个词既能是堡垒又能是斋戒，因为底层都是"牢固"。

同源词：德语 **fasten**（禁食）、古诺斯语 fasta、哥特语 fastan。而英语里 fast 原本还兼有"使牢固"的动词义，这个义项在中古英语中逐渐被 **fasten** 接走——正是这次交接，让 fast 作为动词只剩下了"禁食"一个意思。

## 五、早餐为什么叫 breakfast

break（打破）+ fast（斋戒）= **打破斋戒**。字面意思就是结束从昨晚晚餐到今早第一餐之间的禁食状态。名词始见于 15 世纪中期，由动词短语 break fast 固化而成；当动词用（吃早餐）要到 1670 年代，1793 年又生出"为某人供早餐"的用法。

两个附带的细节：

- **古英语里这餐不叫 breakfast**，而叫 undernmete（undern 指上午九点）或 morgenmete（晨餐）。breakfast 是后来才取代它们的。
- **元音缩短**：break 里的元音是长的，做成复合词第一成分时缩短，于是读音成了 brek-fast。这是古英语复合词的通例，同类的还有 Christ → Christmas、holy → holiday、moon → Monday、sheep → shepherd、wild → wilderness。

**这不是英语独有的命名法。** 罗曼语族管一天第一餐也叫"开斋"：法语 déjeuner、西班牙语 desayuno 同出于俗拉丁语 `*disieiunare`，由 dis-（撤销）加 ieiunare（禁食）构成；英语的 **dine** 同样来自古法语 disner，往上也是"解除斋戒"，原本指的就是一天的第一餐。整个欧洲都在用"开斋"给早餐命名。走别的路的也有：德语 Frühstück 的字面是"早的一块"。

而 ieiunare 这一支还给英语留下了两个远亲：**jejune**（贫乏无味的）与解剖学上的 **jejunum**（空肠）。

## 六、空腹血糖为什么叫 fasting glucose

这个术语的规范写法是 **fasting glucose**，完整的临床叫法是 fasting blood glucose（FBG）或 fasting plasma glucose（FPG），中文译作"空腹血糖"。也会见到 fast glucose 这样的简写，但那不是术语，正式的检验报告与文献里不使用。

- **fasting 在这里是定语**，取 fast 的现在分词："处于禁食状态的"。医学上的定义是**连续 8～12 小时不摄入任何热量**（通常是前一晚晚餐之后不再进食），此时测得的血糖才算空腹血糖。
- **为什么非得空腹**：餐后血糖随食物成分与进食时间剧烈波动，只有空腹值才是能横向比较的基线，诊断阈值也建立在这个基线上。
- **与它配对的是 postprandial**（餐后），来自拉丁语 prandium（正餐）。实验语境里常说 fasted state（禁食态）与 fed state（进食态）。
- **一个交叉印证**：解剖学里的 **jejunum**（空肠）来自拉丁语 jejunus（禁食的、空的），因为古人解剖时这一段肠管常常是空的。所以英语里表达"空"其实有两条词根——日耳曼的 fast 与拉丁的 jejun-，它们各走各的路，最后在医学词汇里撞到了一起：一个说"守戒"，一个说"空着"。中文的"空腹"（字面就是"空的肚子"）接的正是 jejun- 这一支。

## 七、"不吃早餐"该怎么写

英语里**没有专门表示"不吃早餐"的单词**，通行写法是动词短语 **skip breakfast**。skip 的本义是"跳"，引申为"跳过本该做的事"，所以"不吃早餐""不参加面试"都用它。

需要留意一个容易混淆之处：skip 与 breakfast 里的 fast 是两个无关的成分——前者是独立的动词，后者只是"斋戒"义在复合词里的残留，不能把它们拼到一起造出一个并不存在的词。

真要写成名词性说法，惯例是这几个：

| 说法 | 用法 |
|---|---|
| skip breakfast | 动词短语，最常用 |
| breakfast skipping | 名词短语，"不吃早餐"这个行为 |
| breakfast omission | 医学／营养学文献里的正式说法，意为"略去早餐" |
| breakfast skippers | 医学文献里指"不吃早餐的人" |
| unbreakfasted | 形容词，"没吃早餐的"，1640 年代就有：to go unbreakfasted（空着肚子出门） |
| brunch | 不是"不吃早餐"，而是把早餐与午餐并成晚上午的一顿，1895 年前后的混成词 |

顺带一提，breakfast 自己也能当动词（1670 年代）：I breakfasted at seven。

## 八、汉字的"斋"走了同一条路

《说文解字》释"斋"为"**戒洁也**"——本义是祭祀之前洁净身心、戒绝嗜欲，重点在"戒"与"洁"，并不在"不吃"。

它的引申路径与 fast 几乎平行：

```text
斋戒（守戒、洁身）→ 斋期（一段时间内的禁食禁欲）→ 吃斋（素食、不吃荤）→ 斋月
```

对照来看：中文以"戒洁"为起点，英语以"牢牢持守"为起点，两者最后都滑到了"不吃东西"这个日常义上。而两边都还留着各自的另一半：fast 的"牢固"义活在 steadfast、fasten 里，"斋"的"洁净"义则留在"斋戒沐浴"以及引申出的"清静的房间"——也就是"书斋"里。

这说明它不是英语特有的怪现象，而是**宗教纪律这套概念在两个语系里各自留下的化石**。相关的语义演变记录，同目录的《"表"字的语义演变时间线》用的是同一套方法论。
